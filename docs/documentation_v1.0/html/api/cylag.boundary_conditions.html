Submodules¶

cylag.boundary_conditions.compute_bc module¶

cylag.boundary_conditions.compute_bc.compute_boundary_condition(simutime, fset, pset, parameters, i, bnd_j, bnd_stats)¶

Compute boundary conditions

Handles wall rebound, open boundaries, bottom/surface reflections, and updates boundary statistics.

Parameters:

  • simutime (cylag.SimuTime) – Simulation time manager

  • fset (cylag.EulerianFieldSet) – Eulerian field set containing mesh and fields

  • pset (cylag.LagrangianParticleSet) – Lagrangian particle set

  • parameters (cylag.Parameters) – Model parameters

  • i (int) – Particle index

  • bnd_j (int) – Boundary edge index (or -1 if no boundary crossed)

  • bnd_stats (int[:]) – Array for accumulating boundary crossing statistics
