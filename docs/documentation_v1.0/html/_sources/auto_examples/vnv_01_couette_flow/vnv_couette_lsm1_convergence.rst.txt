===============================================================================

LSM-1 model without diffusion (material pathlines):

- **Euler**

    def compute_error(traj, exact_traj):
        nt = len(traj)
        err = 0.
        for k in range(nt):
            dist = np.sqrt((traj[k, 0]-exact_traj[k, 0])**2 + (traj[k, 1]-exact_traj[k, 1])**2)
            err += dist
        return err/nt
